🌐 1. Nghịch Lý Đo Lường: Lý Thuyết vs Live-Coding r = 0.14

Hệ số tương quan r=0.14 cho thấy trắc nghiệm không đo lường được năng lực viết code thực tế. Học viên thuộc định nghĩa lý thuyết nhưng thiếu phản xạ mở IDE tự xây dựng API 4 lớp.

👥 2. Hiện Tượng "Ỷ Lại Nhóm" Trong Đồ Án r = 0.71 vs 0.17

KNM tương quan rất cao với điểm Sản phẩm nhóm (r=0.71) nhưng lại không tương quan với Vấn đáp 1-1 (r=0.17). Cần áp dụng hệ số Git Commit và phỏng vấn độc lập để cá nhân hóa điểm số.

🏫 3. Điểm Nghẽn Chất Lượng Giữa Các Lớp (Giảng Viên) Chênh 7.7 Lần

Cùng 1 khung chương trình nhưng lớp dạy Hands-on Live Coding có điểm thực hành cao gấp 7.7 lần lớp dạy slide. Cần chuẩn hóa đồng bộ giáo án thực hành giữa tất cả các giảng viên.

💼 4. Mô Phỏng Phễu Tuyển Dụng Doanh Nghiệp Đỗ 47.0%

Chỉ 87 / 185 SV (47.0%) đỗ đồng thời cả 3 vòng nếu phỏng vấn tại doanh nghiệp. 29 SV bị rơi rụng oan ở vòng vấn đáp; 20 SV rơi rụng ở vòng Live-Coding.

☕ KHÓA KS24 (JAVA)
Trọng tâm: Concurrency, DevSecOps, AI & Tracing
Kỳ IV
Microservices System IT214 • 2.5 TC Cải Tiến Lõi
⚠️ Lỗ hổng ĐGNL: 53.8% SV trượt tranh chấp dữ liệu; hổng bảo mật IDOR qua Gateway.
  • Bridge 2 buổi đầu: Dạy củng cố @Transactional & Pessimistic/Optimistic Locking JPA.
  • Token Propagation: Feign Client Interceptor truyền JWT qua API Gateway chống IDOR.
  • Modern Tracing: Tích hợp Micrometer + OpenTelemetry + Grafana Tempo (Spring Boot 3+).
  • Tối ưu Docker: Tái sử dụng Docker Compose từ DevOps IT209.
DevOps Fundamentals IT209 • 1.9 TC DevSecOps
⚠️ Lỗ hổng ĐGNL: Học viên thiếu công cụ kiểm tra an ninh mã nguồn tĩnh & quản lý tài nguyên VPS.
  • Lightweight DevSecOps: Quét lỗ hổng tĩnh bằng Semgrep / Snyk trên GitHub Actions.
  • PLG Observability: Setup Prometheus + Loki + Grafana (thay thế ELK Stack dễ gây tràn RAM).
  • DB Migration: Tự động hóa cập nhật schema bằng Flyway / Liquibase.
AI Integration IT213 • 1.9 TC GenAI Agent
⚠️ Xu hướng mới: Chi phí gọi API LLM cao và yêu cầu xử lý Agent dạng đồ thị.
  • Semantic Caching: Dùng RedisVL / GPTCache giảm 80% chi phí API.
  • Advanced AI Agents: Xây dựng Agent đồ thị đa tác vụ với LangGraph / CrewAI.
  • SSE Streaming: Server-Sent Events stream câu trả lời về ReactJS.

🔄 TẦNG 2: QUY TRÌNH & GIẢNG VIÊN (KỲ III - IV)
  • Quy Định "Live-Code Review 3 Phút": Bắt buộc dành 30% thời lượng mỗi buổi Lab để sinh viên thuyết trình giải pháp code cá nhân.
  • Chuẩn Hóa Giáo Án Giảng Viên: Chấn chỉnh phương pháp giảng dạy tại các lớp điểm thực hành dưới 20đ (HCM-CNTT8, HN-CNTT6).
